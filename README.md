# Демо экранов «Атланты Сити. Зима 2027»

Кликабельный макет приложения: 144 экрана в тёмной и светлой темах. Все люди, компании и цифры вымышленные; залы и даты фестиваля настоящие. Это не работающее приложение: входа и синхронизации данных нет.

Страница закрыта от индексации (noindex, robots.txt).

Установка на телефон:
- iPhone: Safari → «Поделиться» → «На экран „Домой“» → «Добавить».
- Android: Chrome → меню (⋮) → «Установить приложение» или «Добавить на главный экран».

Открыть: https://atlantyevents-lab.github.io/atlanty-city-app-demo/

Адрес экрана в хэше, например `#/G3`. Тема переключается в верхней панели.

Источник — закрытый репозиторий приложения, папка `demo/`. Этот репозиторий обновляется скриптом публикации, правки вносятся там.
